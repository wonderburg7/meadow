# H1 -- the function map covers what it says it covers

Status: shipped 11 Sep 2026 | Owner: Dave / Claude Code | Plan:
`plans/design/architecture-review.md`

## What this was

FUNCTION_MAP.md's `FILES` list was a hardcoded seven `scripts/*.gd` files,
so `--check` could confirm the seven's own line numbers hadn't moved but
could not see an eighth script cross the map's own stated 700-line
threshold and go unindexed. F13 found six such files: `bee_foraging.gd`,
`challenge_runner.gd`, `diagnostic_log.gd`, `scenario_actions.gd`,
`game_config.gd` and `input_selection.gd`.

## Specification (as queued)

Level: low. Depends on: nothing. Touches no `scripts/` file.

- **Required reading.** This heading. F13 above. `tools/update_function_map.py`.
- **Files to change.** `tools/update_function_map.py`, `FUNCTION_MAP.md`
  (regenerated, not hand-edited).
- **Files not to change.** Anything in `scripts/`.
- **Requirements.** `FILES` is derived by walking `scripts/*.gd` and keeping
  every file over a stated line threshold, rather than being a hardcoded list.
  The threshold is a named constant set to 700, which is the number the map's
  own header already claims. Each newly covered file gets a one-line
  description in the same voice as the existing seven. `--check` fails when a
  file crosses the threshold and is absent from the map, not only when an
  indexed file's line numbers have moved.
- **Invariants.** The seven files already indexed keep their existing
  descriptions verbatim. The generated format does not change, because
  `CLAUDE.md` and `plans/README.md` both describe how to grep it.
- **Implementation guidance.** The descriptions are the only judgement in this
  slice. `bee_foraging.gd` is the forager's search, scouting, recruitment and
  species-preference behaviour; `challenge_runner.gd` the stage machine, goal
  checks and stage effects; `diagnostic_log.gd` the session JSONL writer,
  counters and capture profiles; `scenario_actions.gd` the headless verbs,
  `when` clauses and layout assertions; `game_config.gd` the balance fields;
  `input_selection.gd` selection, drag and placement resolution.
- **Runtime policy.** None; this is a build-time tool.
- **Automated acceptance.** `python tools/update_function_map.py --check` exits
  zero on a clean tree. Temporarily padding any `scripts/*.gd` past 700 lines
  makes it exit non-zero naming that file. `tools/verify.ps1` stays green.
- **Escalation.** If the threshold turns out to sweep in a file whose functions
  are genuinely not worth indexing, say which and why rather than special-casing
  it in the generator.

## What shipped

`tools/update_function_map.py`'s `FILES` list is replaced by a
`LINE_THRESHOLD = 700` constant and a `discover_files()` that walks
`scripts/*.gd`, counts lines and keeps everything over the threshold,
sorted biggest-first (ties broken alphabetically) so the output stays
deterministic. A `DESCRIPTIONS` dict now separates the hand-written
one-line description for each file from the walk that decides which files
are in scope; the seven existing entries are unchanged verbatim, and the
six newly-covered files each got a description in the plan's own words
(forager search/scouting/recruitment/species-preference;
stage machine/goal checks/stage effects; JSONL writer/counters/capture
profiles; headless verbs/`when` clauses/layout assertions; balance fields;
selection/drag/placement resolution). `--check` now fails separately and by
name when a discovered file has no `DESCRIPTIONS` entry, distinct from the
existing staleness check, so a file crossing the threshold with no
description added is caught rather than silently excluded.

Verified against the live repo: `python tools/update_function_map.py`
regenerated `FUNCTION_MAP.md` with all thirteen files (the original seven
plus the six F13 named) and `--check` passed clean afterwards. Temporarily
padding `main_menu.gd` (659 lines) past 700 made `--check` exit 1 naming
`main_menu.gd` and pointing at the missing `DESCRIPTIONS` entry, then the
file was restored and the tree confirmed clean. `tools/verify.ps1` passed
green on the merged result.
