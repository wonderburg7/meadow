# HC-1 — the command tray's three columns share its width evenly

<!-- CONTEXT: plan | LAYER: immediate-task -->
Status: complete | Owner: Dave / Claude Code | Next: None — slice complete | Dependency: none | Verified: 2026-09-09
Archived 2026-09-09, the day it landed. Delivered from `plans/now/hud-controls.md`.

**Reasoning level: low.** One function, one property, no interface change.

**What Dave reported (C-18, 9 Sep 2026).** The tray is on screen, its gaps
are right, and Job, Focus, Orders and `More…` are all visible and clickable —
every other condition in C-18 passed. But "the tray buttons are all squashed
on the left side of the tray", with the rest of the tray empty. Dave: "the
tray should have three columns evenly spaced columns."

**Cause.** `hud.gd::_build_tray_column()` sets each column wrapper's
`size_flags_horizontal = Control.SIZE_EXPAND_FILL`, but the parent
`command_columns` is an `HFlowContainer`. A flow container lays its children
out at their minimum size and ignores expand flags entirely — that is what
makes it wrap. So each wrapper gets its `custom_minimum_size.x` of 100px and
they pack against the left edge, leaving the rest of the tray's centred width
empty.

**Delivered, in `scripts/hud.gd`.**

- Added `const TRAY_COLUMN_SEPARATION := 16.0`, used in place of the two
  literal `16`s passed to `add_theme_constant_override("separation", 16)`
  for `command_columns` and `cell_primary_columns`.
- Added `_tray_chrome_width()`, returning the tray panel stylebox's left plus
  right content margins.
- Added `_apply_even_column_widths(wrappers: Array)`: splits the tray's inner
  width evenly across however many wrappers it is given, with a
  `TRAY_COLUMN_SEPARATION` gap between each, falling back to
  `custom_minimum_size.x = 0.0` (native `HFlowContainer` wrapping) when the
  even width would be narrower than the widest wrapper's own content.
- `_update_command_tray_width()` now calls this once for
  `[job_column_wrapper, focus_column_wrapper, orders_column_wrapper]` and
  once for `cell_primary_columns.get_children()`, so the cell action columns
  (currently "Reserve for" and "Nursery") get the same even split at
  whatever count they hold, not a fixed three.
- Left `size_flags_horizontal` on the wrappers alone — inert inside an
  `HFlowContainer`, kept so nobody re-adds it believing it is missing.

**Acceptance.** At 1920x1080, select a bee. The Job, Focus and Orders columns
divide the tray's width into three equal parts, with the same gap between
each pair and the same distance from each end. Select a comb cell and the
cell columns do the same. At 800x600, where a third of the tray is narrower
than the widest button, the columns wrap onto more rows instead and nothing
is clipped.

**Check filed:** C-18, in `checks/ready.md`, unchanged — it already asked for
exactly this condition, so it needed no re-filing.
