records. They are deliberately excluded from routine Claude context and must
not be used to select work. Their paths may describe the repository as it was
at the time; follow current routing in `NEXTSTEPS.md` and `plans/README.md`.

Use targeted search only when a current task needs a decision, acceptance
criterion, migration rationale, or delivered-slice evidence that is not
distilled elsewhere. Major current pointers are:

| Topic | Current or durable pointer |
| --- | --- |
| Challenge 1 / Challenge 2 boundary | `plans/archive/CHALLENGE1_2026-09-15.md` |
| UI | `plans/now/ui.md` |

| Confirmable player behaviour | `checks/ready.md` |

The old `CHATGPT_*` records are historical Codex evidence only. New work uses
the same shared plan files as Claude and remains subject to `CHATGPT.md`.
