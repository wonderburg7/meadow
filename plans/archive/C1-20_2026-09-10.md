# C1-20 — the designation stage asks for the designation it names

Archived 10 Sep 2026 from `plans/archive/CHALLENGE1_2026-09-15.md`. Landed on `master` in
`e9845fe`. Full specification preserved here.

**Reasoning level: medium.** One goal function was shared with Challenge 2
and gated three failed checks.

**Confirmed root cause.** `_goal_check_cell_designated()` accepted any
nectar, pollen or brood designation. `HiveCell.add_resource()` automatically
sets an empty cell's designation on its first deposit, so the queen's nectar
delivery at 1.10 satisfied the pollen-designation stage as soon as it opened.
The player never saw 1.13 (C-30), never reserved a pollen cell, and therefore
never received the pollen-cell nectar call-out (C-31).

**Required change.** Add `pollen_cell_designated` as a polling goal and bind
it to `_goal_check_pollen_cell_designated`. It passes only for a cell whose
`designated_type == "pollen"` and `designation_is_explicit` is true. Stage
1.13 uses that new goal; Challenge 2 stage 2.3 and the existing
`cell_designated` predicate remain unchanged. The cell popup's designation
path must retain its existing explicit designation signal, and automatic
deposit must not acquire it.

**Constraints.** Do not alter `hive_cell.gd`, `hive.gd`, `GameConfig`, save
format behaviour, Challenge 2's stage 2.3, or the existing shared goal.
The goal is stateless: it polls the rebuilt hive cells after a checkpoint and
needs no runner reset.

**Edge cases.** Reserving the first cell for pollen is valid. Unreserving and
reserving again naturally makes the polling goal false and true. A restored
checkpoint supplies a fresh cell list that the predicate reads directly.

## What shipped

`GOAL_CADENCE` and `_goal_registry` now declare `pollen_cell_designated` as
a polling goal. `_goal_check_pollen_cell_designated` requires both a pollen
designation and the existing player-choice flag. Stage 1.13 uses it, while
Challenge 2 continues to use `cell_designated`; `docs/challenge-stages.md`
was regenerated.

The UI designation path already calls `HiveCell.set_designation()` with its
default `explicit: true`, and the existing save path already preserves
`designation_is_explicit`, so neither needed a change.

**Validation.** `tools/verify.ps1 -Quiet` passed: source checks, balance
tests, function map, stage reference, and documentation checks. Godot 4.7.1
also completed a headless editor parse; its only diagnostics were sandboxed
user-directory cache writes.

**Hands-on follow-up.** C-30 and C-31 remain in `checks/ready.md` unchanged
for Dave to re-run against the repaired pollen arc.
