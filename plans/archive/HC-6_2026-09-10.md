# HC-6 — Dr Gallerin's bubble can be paged back through

**What Dave asked (9 Sep 2026).** "Add a feature so there's arrows in Dr G's
speech bubble you can cycle through what he's previously said."

**What shipped.** `_history: Array[String]` and `_history_index: int` on
`GallerinPanel`. `_show_bubble()` (the path every real prompt and the icon's
"show the last thing said" replay both go through) calls `_push_history()`,
which appends the shown text unless it exactly repeats the last entry,
points `_history_index` at the newest slot, and drops the oldest entry past
50 so a long run cannot grow the array without bound. `◀`/`▶` buttons sit in
the button row to the left of Dismiss, styled with the same
`UiTheme.button_stylebox()` overrides the rest of the game's buttons use,
and step `_history_index` back and forward through `_show_history_entry()`,
which shows an entry in full rather than typing it out (HC-5's typing effect
stays reserved for genuinely new lines). `_update_history_buttons()` keeps
`◀` disabled at the oldest entry and `▶` disabled at the newest rather than
leaving either silent. `_process()`'s `_fire_due_prompts()` call is guarded
on `_history_index == _history.size() - 1`, so the scheduler's queue keeps
accumulating while the player is paged back to an older line -- a prompt
that falls due mid-read is shown the moment they return to the newest one,
rather than snatching the bubble away from what they're reading.

**Verification.** `tools/verify.ps1` green. Hands-on: C-39 in
`checks/ready.md`, covering the paging, both disabled ends and the
held-prompt case.
