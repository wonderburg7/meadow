# CR-3 — align permissions with the intended Git lifecycle

Completed and merged to `master` on 2026-09-09.

## Scope

Create a least-privilege Meadow permission profile for repository content,
shared Git metadata and the worktree root; scope network access to the
configured Git remote; make the canonical slice lifecycle commands available
without per-step approval discovery; and configure Git safe directories during
environment setup.

## Acceptance

`doctor` exercises a disposable Git ref without leaving it behind, and a mock
slice can claim, commit and close without a manual Git repair.

## Delivered

The trusted project now selects the `meadow` profile, grants only the primary
checkout, its shared `.git` metadata and `.worktrees` write access, limits
network traffic to GitHub, and exposes only the canonical `doctor`, `start`
and `finish` lifecycle commands through its reviewed rule. Windows setup adds
the primary checkout and worktree parent to Git's safe-directory list.

The lifecycle doctor now uses a disposable `git update-ref` probe, and focused
regressions cover the permission configuration and a complete mock lifecycle.
