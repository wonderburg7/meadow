# L-8 — a Godot failure names which of five things broke

Shipped 17 September 2026.

**Objective.** Distinguish MCP unavailable, editor unavailable, a baseline
environment crash, a scenario failure and a genuine product failure. Before
this slice all five shared one exit path, and one of them (a fresh
worktree's missing `.godot` import cache) was a false alarm about the game.

**What shipped.** `Get-GodotCapability` in `tools/slice.ps1` returns one of
five states with a one-line reason, checked in this order: `mcp_unavailable`
(the command `.mcp.json` configures for the Godot MCP server cannot be
resolved on PATH), `editor_unavailable` (`Get-ConfiguredGodotPath` found
nothing, or the path it found does not exist), `import_cache_missing` (no
`.godot` directory), `environment_crash` (the executable exists and the
import cache is present, but `--headless --disable-crash-handler
--quit-after 1` still exited non-zero or never returned within 20 seconds),
and `ready`. `import_cache_missing` is checked ahead of the boot probe
deliberately: a missing import cache fails that same probe with a non-zero
exit and would otherwise be misreported as `environment_crash` -- the exact
false alarm this slice exists to name on sight. `doctor` reports the result
as `godot_capability`; only `editor_unavailable` still blocks `doctor`
itself, unchanged from before this slice, since `Get-DoctorEnvironmentFailures`
was left as it was.

`docs/headless-run-contract.md` gained a "Diagnosing a Godot failure"
section naming all five states and what each means for the reader; there was
no prior triage prose there to replace.

**Tests.** `tests/test_source_checks.py::SliceDoctorTest::
test_godot_capability_names_each_failure_state` drives all five: an
unresolvable command in a fixture `.mcp.json`, a `.codex/config.toml`
`GODOT_PATH` that does not exist (the pre-existing failure, unchanged), a
fixture with no `.godot` directory, a real executable (`powershell.exe`)
that rejects the probe's arguments, and one that accepts them (`cmd.exe`,
standing in for Godot since a genuine access violation is not reproducible
portably).

**Expected improvement.** 36 failed headless runs stop starting their triage
from scratch, and the import-cache false alarm is named on sight.

**Next slice.** L-9.
