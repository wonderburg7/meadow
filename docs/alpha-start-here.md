MEADOW — START HERE

Unzip the whole archive anywhere you like. Keep Meadow.exe and its pack
file together, then double-click Meadow.exe to play.

Windows may show an "unknown publisher" warning because this alpha is
unsigned. For the Meadow build Dave sent you, choose "More info", then
"Run anyway".

Start with Challenge 1 to learn the controls, or choose Colony Run for the
full game. The Settings button on the main menu lets you adjust text size
and appearance before you start.

Use the numbered speed buttons at the top of the game: 1 is normal speed,
2 is double speed and 4 is quadruple speed. Pause freezes the colony while
you look around and give orders. Return to 1 when you want time to react.

Save your run through the settings cog. Saves stay on this computer, outside
the unzipped game folder, in %APPDATA%\Godot\app_userdata\Meadow\saves\.
Paste that path into File Explorer's address bar to find them. Keep that
folder if you want to continue your colony after replacing the game build.

When you have finished playing, use Feedback on the main menu to open
Dave's form. Note the build id in the menu's bottom-right corner and copy
it into the form, so Dave knows which version you played. Tell him what
you reached, what confused you and anything that broke.
