## Implementation block: E12-1

1. **Outcome and owner**: Candidate Jules task to add a dedicated `--list` option to `tools/heading.py`.
2. **Files**: `tools/heading.py`, `tests/test_heading_tool.py`, `tests/test_heading_helpers.py` (all free in preflight).
3. **True now**: `tools/heading.py` requires two positional arguments: `file` and `heading`. If an agent or script only wants an index of available headings, passing an empty string or mismatched pattern causes an exit status of 1 and prints headings to `sys.stderr` as an error: `AGENTS.md: no heading matches 'nonexistent'. Headings are:`. Baseline command: `python tools/heading.py AGENTS.md "nonexistent"` returns exit code 1.
4. **Do**:
   - In `tools/heading.py::main`, add optional `--list` argument (`parser.add_argument("-l", "--list", action="store_true", help="list all headings in the file and exit 0")`).
   - Make the `heading` positional argument optional when `--list` is specified (`nargs="?"`).
   - When `--list` is provided, print each heading formatted with its level indentation (`{'#' * level} {text}`) to `sys.stdout` and return 0.
   - In `tests/test_heading_tool.py`, add tests asserting that `--list` outputs headings to stdout and exits with code 0.
5. **True afterwards**: Running `python tools/heading.py AGENTS.md --list` cleanly prints the document's heading table of contents to stdout with exit code 0 without raising tool errors or dumping stderr noise.
6. **Must retain**: UTF-8 stream reconfigurations, ATX heading regex parsing (`HEADING_PATTERN`), fenced code block exclusion (`FENCE_PATTERN`), case-insensitive substring matching for normal queries, exit 1 on missing file or unmatched heading when `--list` is not passed.
7. **Verify**: `python tools/heading.py AGENTS.md --list` exits 0 and prints TOC; `python -m unittest tests.test_heading_tool` passes.
8. **Saving and cost**: Prevents error-handling loops, avoids dumping unintended section bodies, and saves ~200-600 tokens per document navigation query.
9. **Reasoning**: Low risk CLI enhancement; Stop if: breaking positional argument parsing for existing callers (`tools/slice.ps1`).
10. **Reviewer entry point**: `tools/heading.py::main` and `tests/test_heading_tool.py`.

## Implementation block: E12-2

1. **Outcome and owner**: Candidate Jules task to add `--all-unit` module discovery to `tools/run_tests.py`.
2. **Files**: `tools/run_tests.py`, `tests/test_run_tests_helpers.py` (free in preflight).
3. **True now**: `tools/run_tests.py` requires callers to pass test module names explicitly as positional arguments. As a result, documentation and session scripts require an unwieldy bash pipeline:
   ```bash
   modules=$(ls tests/test_*.py | sed 's#^tests/#tests.#; s#\.py$##' | grep -v -x -e tests.test_slice_lifecycle -e tests.test_two_lane_closeout)
   python tools/run_tests.py --private-user --label "unit tests" $modules
   ```
   This pipeline is 138 characters long, brittle, and not directly executable on Windows PowerShell 5.1 without translation.
4. **Do**:
   - In `tools/run_tests.py`, add helper function `discover_unit_modules(root: Path) -> list[str]` discovering all `tests/test_*.py` files, excluding slow/lifecycle tests (`tests.test_slice_lifecycle`, `tests.test_two_lane_closeout`).
   - In `tools/run_tests.py::main`, add `--all-unit` flag. When passed (or when no modules are supplied and `--all-unit` is set), populate `modules` with `discover_unit_modules(ROOT)`.
   - In `tests/test_run_tests_helpers.py`, add unit tests asserting that `discover_unit_modules` returns the expected set of modules with lifecycle tests excluded.
5. **True afterwards**: Sessions and scripts run `python tools/run_tests.py --private-user --all-unit` directly without requiring intermediate shell pipelines or environment-specific utilities.
6. **Must retain**: Existing module-specific arguments, case expansion (`--cases`), worker pool threading, timings persistence, and game test skip logic (`--game-tests-since`).
7. **Verify**: `python tools/run_tests.py --private-user --all-unit` runs unit test suite cleanly; `python -m unittest tests.test_run_tests_helpers` passes.
8. **Saving and cost**: Eliminates repeated shell pipeline syntax across agent prompts and instructions, saving ~150-300 tokens per test run invocation and preventing cross-platform shell syntax errors.
9. **Reasoning**: Low risk test runner feature; Stop if: module discovery alters test execution order in a way that breaks isolated test cases.
10. **Reviewer entry point**: `tools/run_tests.py::discover_unit_modules` and `tests/test_run_tests_helpers.py`.
