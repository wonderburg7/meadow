## Implementation block: E30-2

1. **Outcome and owner**: Candidate Jules task to implement a standalone validator `tools/check_scenarios.py` (and test in `tests/test_check_scenarios.py`) validating scenario action verbs and structures offline.
2. **Files**: `tools/check_scenarios.py` (`free` in preflight), `tests/test_check_scenarios.py` (`free` in preflight; read-only: `test_scenarios/*.json`, `scripts/scenario_actions.gd`).
3. **True now**: `tests/source_checks.py::check_scenario_condition_keys` inspects `LEGACY_WHEN_KEY_MAP`, `LOCAL_WHEN_KEYS`, and `Conditions._met_key`, but has no check for action `"do"` values. If a scenario author specifies `{"do": "mine_queue"}` instead of `{"do": "queue_mine"}`, `scenario_actions.gd::_execute` logs an unknown `'do'` value to `result.json` at runtime, which is invisible during static pre-commit checks.
4. **Do**:
   - In `tools/check_scenarios.py`, extract known verbs dynamically or from `scripts/scenario_actions.gd::_execute` match cases.
   - Scan every JSON fixture in `test_scenarios/` and verify that every object in `"actions"` has a recognised `"do"` verb (or `"comment"` / `"disabled"` key).
   - Add unit tests in `tests/test_check_scenarios.py` asserting that unknown verbs are flagged and that all 152 real scenarios pass.
5. **True afterwards**: Scenario authoring errors are caught instantly via fast Python CLI without waiting for Godot headless test suites.
6. **Must retain**: Allowances for mock actions, comment fields, and legacy scenario compatibility.
7. **Verify**: `python -m unittest tests.test_check_scenarios` and `python tools/check_scenarios.py`.
8. **Saving and cost**: Eliminates 1,000-2,000 tokens of speculative debugging on failed or inert headless scenario runs; runtime is <0.15s.
9. **Reasoning**: Low risk linting tool.
10. **Reviewer entry point**: `tools/check_scenarios.py`.
