## Implementation block: E18-1

1. **Outcome and owner**: Candidate Jules task to add static unit test assertions in `tests/test_save_migrations.py` verifying that new entity save fields are purely additive and maintain old-save fallback contracts.
2. **Files**: `tests/test_save_migrations.py` (`free` in preflight; read-only: `scripts/save_game.gd`, `scripts/saving.gd`, `scripts/save_migrations.gd`).
3. **True now**: `.claude/rules/saving.md` documents: "A new field is additive unless an old save would load wrong without it (Dave, 7 Oct 2026, save review). Add it with a `.get()` default that matches how an old save behaved, with no `FORMAT_VERSION` bump and no migration". While tests exist for `drone`, `mated`, and `pending_seal`, each slice worker invents ad-hoc unit test assertions to prove additive compliance.
4. **Do**:
   - In `tests/test_save_migrations.py`, add a generic entity field contract test class `EntityAdditiveFieldsTest`.
   - Implement parameterised helper methods checking that for any new key added to `_bees_data` or `_cells_data` in `scripts/save_game.gd`, the corresponding restore routine in `scripts/saving.gd` reads it using `.get(key, default)` with an appropriate fallback value.
   - Assert that `FORMAT_VERSION` in `scripts/save_game.gd` is not bumped without a corresponding `_migrate_<N>_to_<N+1>` function in `scripts/save_migrations.gd`.
5. **True afterwards**: Future slice workers adding fields (such as `health` in ED-1c) can run `python -m unittest tests.test_save_migrations` and immediately know their field follows the established additive pattern.
6. **Must retain**: All existing migration tests from v1 up to v7, milestone days tests, and seal flag tests.
7. **Verify**: `python -m unittest tests.test_save_migrations`.
8. **Saving and cost**: Avoids 1,500-2,500 tokens of full-file inspection across `scripts/save_game.gd` and `scripts/saving.gd` per save slice; test runs in <0.2s without booting Godot.
9. **Reasoning**: Low risk unit test guard. Stop if AST inspection of Godot dictionaries creates false positives.
10. **Reviewer entry point**: Inspect `tests/test_save_migrations.py`.
