# C-88 -- Skill names in big hexes, drag and zoom

What this checks: Start a run and click the Skills button (top right) to open the skill tree. Read a few skill names inside their hexagons, drag the tree with the left mouse button held, then scroll the wheel down until the whole tree is on screen.

PASS: Every skill's name is readable inside its hexagon at the opening zoom, dragging moves the tree, and the wheel zooms out until the whole tree is visible.

If it fails, SK-2 reopens: the font size or text width in `scripts/skill_tree_panel.gd::SkillGrid._draw`, or the zoom limits in `_min_zoom`.
