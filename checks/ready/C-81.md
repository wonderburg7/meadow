# C-81 -- Nurse stays locked until Nurses is bought

What this checks: start Challenge 2 from the main menu (not level 7: you cannot start level 7 from the main menu and expect a locked Nurse, because every Scenario's queen backs up as a Nurse and owns Nurses from the start). Before Challenge 2.5, click the queen and open the Job row's "Change to…" menu, then click an empty built comb cell and open its Raises row. At 2.5 open Skills, buy Nurses (free there), close the tree and look at both menus again.

Buy needs UT-2 (`plans/now/ui-texture-polish.md`) to be clickable, so run this after UT-2 lands.

PASS: before buying Nurses neither menu offers Nurse; after buying it both do (the one that was open when you bought it offers Nurse as soon as the tree closes).

If it fails, `Availability.role_query` is not what the menu reads (`hud.gd::_role_offered`), or the purchase is not re-applying it (`hud.gd::refresh_role_gating`).

Owner: `plans/now/brood-spine.md`
