# C-176 -- The skill tree says how much of a store is sealed or unripe

What this checks: in a run with some honey sealed (select a full honey cell, press Sealed in its popup and wait for the cap), open the skill tree (Skills, top right) and read the stores line at its top, then hover a skill you cannot yet afford.

PASS: the stores line shows the spendable amount with "(+N sealed or unripe)" beside any store that has more held, and the blocked skill's tooltip names what is held but not spendable, so it is clear why the tree and the top-left stores line differ.

If it fails, the note in `scripts/skill_tree_panel.gd` (`_held_not_spendable`, the stores text and the blocked-cost tooltip) changes; if the tree still refuses a skill whose spendable stores cover it, that is a separate bug in its cost check, to be reported with the numbers shown.
