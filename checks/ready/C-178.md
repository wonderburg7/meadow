# C-178 -- Narrow a crowd by n, youngest and oldest

What this checks: start a run, drag a box round a crowd of bees so the left
panel says "N bees selected", then use the new "Select n" row under that
text: step the number with `<<` `<` `>` `>>` and press Select, then try
"Select youngest bee" and "Select oldest bee" on a fresh crowd.

PASS: Select keeps that many bees, the ones nearest the middle of the crowd (say if you want a different rule), and youngest and oldest each leave one bee, the right one.

If it fails, RR-22 reopens; if only the nearest-the-middle rule is wrong, change `narrow_selection_to_n` in `scripts/input_selection.gd`.
