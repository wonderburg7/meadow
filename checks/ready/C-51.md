# C-51 -- the settings window is about a third of the screen's width, not half

Open the settings cog in a run, at the default text scale on a maximised
1920x1080 window.

PASS: the window is roughly a fifth of the screen wide, the four action
buttons and the three Triggers buttons each read in full without being cut
off, and no row forces a horizontal scrollbar.

Owner: `plans/archive/UI-B-1_2026-09-12.md`.

Measured headlessly before and after: the panel's width went from 920px to
358px on a 1920px viewport. The three Triggers buttons used to share one
row, and a button's minimum width is its whole label, so their combined
labels set the window's width.
