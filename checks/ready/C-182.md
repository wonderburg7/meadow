# C-182 -- PN-3: close Goals, save, load -- it is still closed; open, save, load -- open

What this checks: start a Colony Run from the main menu. Press Goals (top
right, second button row, beside Skills) so the goals list under the top bar
closes. Open the settings window, press Save run, then press Saves… there
and Load that save: the list is still closed. Press Goals to open it, save
and load the same way: the list is open. Then re-run C-150.

PASS: after each load the goals list is open or closed exactly as it was when that save was made.

If it fails, PN-3 reopens: the save's `goals_collapsed` key
(scripts/save_game.gd) is not reaching the shelf on load
(scripts/saving.gd::_restore), and a HUD-plan slice may be needed.
